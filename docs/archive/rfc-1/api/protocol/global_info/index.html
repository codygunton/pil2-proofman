class protocol.global_info.GlobalInfo[source]#

Global configuration from pilout.globalInfo.json.

Matches C++ GlobalInfo struct from common/src/global_info.rs

Fields:

name: Build name (e.g., “build”) curve: Curve type (“None”, “BN128”, “BLS12-381”) lattice_size: Size for lattice expansion (368 for CurveType::None) n_publics: Number of public inputs num_challenges: Challenge counts per stage transcript_arity: Poseidon2 transcript arity (typically 4)
